## 6. 연구 추진 방법 (검증 흐름, 강제 아님)

PI 가 권하는 흐름은 아래와 같다. Step 분해·일정·파일 경로는 피지시자가 자율적으로 정리한다.

1. **현행 관찰 (감사)** — 추측 아닌 실제 관찰·기록
2. **대안 프로토타입** — §4 대안들을 비교 가능한 상태로 구성 (완성된 구현 아님)
3. **비교 평가** — §5 기준으로 정성 평가 + 가능하면 간단 왕복 테스트
4. **결론 도출** — 평가 근거로 v1 안 선정, 선정 근거 리포트 작성 → PI 리뷰·승인
5. **결론안 한정 프로토타입·검증** — 승인안에 한해 간단 converter·왕복 테스트 (검증 도구 수준)
6. **리스크 감지 시 범위 재합의** — 기한 연장보다 PI 와 범위 재합의 우선
