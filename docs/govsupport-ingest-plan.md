## 제외 대상

- 이미지 파일 (PNG/JPG) 163,132개 — G 는 텍스트 검색만
- 바이너리·코드 (DB/JS/TS/pak/map) ~1,600개
- ZIP 재귀 풀지 않음 (`검출이미지및영상.zip` 등 이미지 덩어리)
- `.DS_Store`, 숨김파일

## 실행 순서

1. **샘플 ingest 테스트** — 소규모 디렉터리(예: `2025년 스마트공장 공급기업 기본진단 서류`, 55문서) 하나로 `/ingest/nas` 동작 검증
2. HWP parser 동작 여부 확인 (로그 tail + G `/search/hybrid` 로 검증)
3. **본격 ingest** — 위 8개 namespace 순서대로 `/ingest/nas` 호출
4. **검증** — namespace 별로 `/search/hybrid` 3~5건 샘플 쿼리
5. 완료 후 `GET /namespaces` 결과 스냅샷 기록

## 리스크 / 주의

- **HWP/HWPX parser**: Gateway·G 구현 불명확. 샘플 테스트에서 실패 시 별도 변환(libhwp·hwp5proc) 필요
- **큰 PDF**: OCR 필요한 스캔본 혼재 가능 — parser 가 빈 text 뱉으면 skip
- **사업 중복**: 2025년/ vs 최상위 중복 (예: 2025년 AI바우처 vs 2025년/2025년 AI바우처) — 동일 namespace 에 들어가므로 문제 없음, 단 dedup 는 G 내부 책임
- **PII**: 회사명·대표자명·연락처 포함. 사용자 본인 work 이지만 외부 공유 금지
